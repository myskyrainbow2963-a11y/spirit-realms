# Opening This Project

Use the standard Godot executable for this project:

`E:\Program Files\godot\Godot_v4.7.1-stable_win64.exe`

This project is pure GDScript. Do not open it with a GodotSharp / .NET / Mono debug build from `C:\Users\yuxia\Desktop\GodotSharp`, because that build expects a `.NET assemblies` directory and can show:

`Unable to find the .NET assemblies directory.`

Quick launch files:

- `OPEN_WITH_GODOT_STANDARD.bat` opens the editor.
- `RUN_GAME_STANDARD.bat` runs the game directly.
